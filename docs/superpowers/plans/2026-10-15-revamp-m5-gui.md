# Revamp M5 (GUI) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Revamp window in the owner's applications menu that does what the CLI does: shows the Revamped apps with their update state, patches, updates, skips and rolls them back with live progress and readable failure reports, manages bundle sources and frees disk space. It is a Tauri v2 window around `revamp serve`, installed per-user without root.

**In plain words, what M5 adds:**
- **The window.** App list with badges that tell a new release ("4.1.7 out") from new patches for the version you run ("New patches"), and "Update all". Each app has a version picker, patch toggles and options, Patch and Dry run with the running patch named in the progress, the full report with "Copy report" when something fails, Skip for a release you don't want, and Roll back. A Sources screen adds (with a preview you trust), removes and checks sources, showing each pinned SHA-256. A Storage screen shows what Revamp keeps on disk and frees the rest.
- **The engine underneath.** Progress events from patch jobs; check results that say "new patches" when a source's bundle changed for the installed version (and `revamp update` re-patches for it); skipped releases; storage sizes and removal.
- **`revamp serve`.** The single `revamp` binary answers JSON-RPC 2.0 on stdin/stdout; the window starts it as its sidecar.
- **Installing it.** `npm run gui:install` installs the CLI, builds the window and puts "Revamp" in the menu. The daily check's notification gets an "Open Revamp" button.

**Architecture:**
- **Engine:** `api.ts` (`progress` option, `JobProgress`, `fitsVersion`), `job.ts` (`runJob` patch-start hook), `sandbox.ts` and `runner.ts` (event lines on the child's stderr), `updates.ts` (statuses `patches` and `skipped`, `skipVersion`, re-patch in `updateApp`), `bundle-sources.ts` (sources keep their changelog), new `storage.ts`.
- **CLI:** new `serve.ts` (JSON-RPC handler and stdio loop), `bundle-for.ts` (one bundle choice for the CLI and serve), `notify.ts` (one notification, with "Open Revamp").
- **GUI (`packages/gui`):** Vite + React + TypeScript web UI (`src/`), whose logic lives in `model.ts` and `rpc.ts` for the Node tests; Tauri v2 shell (`src-tauri/`) with the shell and notification plugins; `scripts/` for the icon, the sidecar link and the per-user install.

**Decisions (the owner's, then the planner's rulings):**
1. **Screens** as in the approved mockups (2026-10-15): app list, app detail, Sources, Storage. Sources are not reorderable: the first added wins.
2. **Extras from Morphe Manager** (owner's pick): update clarity (new release vs new patches, skip, "patched with", Update all), clearer results (failure report with copy, back to the selection, a notification when a job ends in the background, progress naming the running patch), storage panel. Not now: patch list polish, per-app source choice, add-source links, saved selections, search and filters.
3. **Rust** is installed with rustup in `~/.rustup` and `~/.cargo`, with no shell edits (owner), so commands put `~/.cargo/bin` on `PATH` like Node 26. The WebKitGTK development packages were installed by the owner with apt.
4. **No `selection.set` method.** The window sends its toggles and options with each job, and the engine saves the selection after an install, as with the CLI's flags.
5. **No `job.patchResult` or `job.done` notifications.** The reply to `job.patch` and `job.update` carries every patch result and the CLI's report text; `job.progress` is the only notification.
6. **Methods beyond §9's list:** `check.last`, `check.skip`, `storage.list`, `storage.remove`, and the two-step `sources.prepare` → `sources.add`. `sources.add` takes only a token from a preview made in the same `serve` session, so a message can't pin a hash the user never saw.
7. **One `revamp` on disk.** The window's sidecar is a link to the installed CLI, `~/.local/share/revamp/bin/revamp`, rather than a second 150 MB copy, so the timer and the window always run the same version.
8. **"New patches"** means the installed version was patched with another bundle than the one its source pins now. The check lists the patches the saved selection would add; `revamp update` re-patches the installed version in that case.
9. **Skipping** quiets checks, badges and notifications for that release only; `revamp update <app>` still installs it when asked.
10. **One notification per check**, listing every app with news, instead of one per app; with the window installed it has "Open Revamp", which starts the window with `systemd-run --user` so it survives the end of the check's service.
11. **No packages.** `tauri build --no-bundle` and a per-user install script, since §9 asks for no root.
12. **Tests:** Node tests cover the GUI's `model.ts` and `rpc.ts` (Node can't run TSX). The screens are checked in a browser through a dev bridge (Vite's websocket to `revamp serve`), and the window itself by a launch smoke test and the owner's acceptance.

## Review Focus

1. **A message to `serve` naming a source or hash the user never previewed** must not add a source. Pinned in Task 4 (`sources.add` takes only a same-session token).
2. **Malformed JSON-RPC** (not JSON, no `jsonrpc`, wrong parameter types, unknown methods) must get an error reply, never stop `serve`. Pinned in Task 4.
3. **A bundle writing fake progress lines** must not break the job or the error text. Pinned in Task 1 (malformed event lines stay error text; only well-formed fields reach the GUI).
4. **A storage id the engine didn't list** (`release:../../etc`), or an item in use, must be refused. Pinned in Task 3.
5. **A check made before an update** must not badge the version installed since. Pinned in Task 5 (`badgeFor`).

### Task 1: Job progress, including the patch that is running

**Model:** `sonnet` / `medium`

**Files:**
- Modify: `packages/engine/src/job.ts` (`runJob` hook), `packages/engine/src/sandbox.ts` (event lines), `packages/engine/src/runner.ts`, `packages/engine/src/api.ts` (`progress` option), `packages/engine/src/index.ts`
- Test: `packages/engine/test/api.test.ts`, `packages/engine/test/sandbox.test.ts`

**Interfaces:**
- Consumes: M1's `runJob`, `runSandboxed` and `patchApp`; M1's `downloadVerified` already accepts `onProgress(received, total)`.
- Produces:
  - `runJob(bundle, input, store, onPatch?: (patch: string, index: number, total: number) => void)`: `onPatch` hears each patch in plan order as it starts, by label (internal patches included).
  - `EVENT_PREFIX = "revamp-event "` (sandbox.ts). A child's stderr line that starts with it carries one JSON event. `runSandboxed(job, access, { entry?, timeoutMs?, onEvent? })` passes parsed events to `onEvent` and keeps every other line, including one that fails to parse, as error text.
  - The runner writes `revamp-event {"patch":…,"index":…,"total":…}` for each patch.
  - `type JobStep = "download" | "extract" | "patch" | "repack" | "install"`; `interface JobProgress { step; percent?; patch?; index?; total? }`; `PatchAppOptions.progress?: (e: JobProgress) => void`. Download percent events come only when the size is known, and only when the whole number changes. Patch events keep only well-formed fields, because the child runs bundle code. Both types are exported from `@revamp/engine`. `log` lines are unchanged.

**Files:**
- Modify: `packages/engine/src/updates.ts` (whole file), `packages/engine/src/api.ts` (`fitsVersion`), `packages/engine/src/bundle-sources.ts` (`changelog`), `packages/engine/src/index.ts`, `packages/cli/src/main.ts` (no notification for a skipped release)
- Test: `packages/engine/test/updates.test.ts`, `packages/engine/test/bundle-sources.test.ts`

**Interfaces:**
- Consumes: M4's `checkUpdates`, `updateApp`, `checkMessage`, `bundleForApp` (returns the `source` it chose), the install receipt (`receipt.bundle.sha256`, `receipt.patches`, `receipt.release.untested`), `loadSelection`, `patchesForApp`.
- Produces:
  - `fitsVersion(p: PatchInfo, appId, version): boolean` in `api.ts`, which `listPatches` now uses too.
  - `BundleSource.changelog?: string`, saved from `bundle.json` by `prepareSource` (GitHub and URL sources).
  - `AppCheck.status` gains `"patches"` and `"skipped"`, plus `bundle?: { name; version; changelog? }` and `newPatches?: string[]`.
    - `"patches"`: no newer release, but the app's source pins another bundle than the one `current` was patched with. `newPatches` lists the patches it offers for `current` that the receipt lacks and the saved selection turns on.
    - `"skipped"`: the newer release is the skipped one; no dry run.
  - `checkMessage` for these: `Demo 1.0.0: Demo bundle 1.1.0 has new patches for it (Say hi); re-patch to apply them`, `… is out; re-patch to use it`, `Demo 3.0.0 out (skipped)`.
  - `loadSkipped(paths): Record<string, string>` and `skipVersion(paths, appId, version | null)`, backed by `<state>/skipped.json`.
  - `updateApp(appId, o & { force?, progress? })` re-patches `current` with the newer bundle when there is no newer release but the bundle changed, keeping `force` for an untested install. `progress` reaches `patchApp`.
  - `revamp check --notify` doesn't notify a skipped release.

 * Refreshes the sources, then for each installed app looks up its newest release and, if it is newer than

    if (!installed.current) continue;

    try {
      const { bundlePath, source, description, app, latest } = await newest(installed.appId, o);
      const listed = isStable(app, latest);
      const experimental = Object.hasOwn(app.versions, latest) && !listed;
      Object.assign(check, { appName: app.name, latest, listed, ...(experimental && { experimental }), status: "up to date" });
      if (compareVersions(latest, installed.current) > 0) {
        if (skipped[app.id] === latest) check.status = "skipped";
        else {
          const r = await patchApp({ ...o, appId: app.id, bundlePath, version: latest, force: !listed, dryRun: true });
          Object.assign(check, { status: "update", ...patchCounts(r.results), aborted: r.aborted });
        }
      } else if (bundleChanged(installed, source)) {
        const { name, version } = description.manifest;
        Object.assign(check, { status: "patches", bundle: { name, version, ...(source.changelog && { changelog: source.changelog }) }, newPatches: newPatches(o.paths, installed, description) });
      }
    } catch (e) {
      check.error = e instanceof Error ? e.message : String(e);
    }
    apps.push(check);
  }

  mkdirSync(o.paths.state, { recursive: true });
  const file = join(o.paths.state, "last-check.json");
  writeFileSync(`${file}.tmp`, `${JSON.stringify(result, null, 2)}\n`);
  renameSync(`${file}.tmp`, file);
  return result;
}

export function checkMessage(c: AppCheck): string {
  if (c.status === "failed") return `Couldn't check ${c.appName}: ${c.error}`;
  if (c.status === "up to date") return `${c.appName} ${c.current} is up to date`;
  if (c.status === "patches") {
    const about = `${c.appName} ${c.current}: ${c.bundle!.name} ${c.bundle!.version}`;
    return c.newPatches?.length ? `${about} has new patches for it (${c.newPatches.join(", ")}); re-patch to apply them` : `${about} is out; re-patch to use it`;
  }
  if (c.status === "skipped") return `${c.appName} ${c.latest} out (skipped)`;
  const out = `${c.appName} ${c.latest} out`;
  if (c.aborted) return `${out}, but its patch job fails: ${c.aborted}`;
  const counts = `${c.applied}/${c.total}`;
  if (c.experimental) return `${out}, experimental in your bundles (${counts} patches apply)`;
  if (!c.listed) return `${out}, not yet in your bundles (untested: ${counts} patches apply)`;
  if (!c.failing?.length) return `${out}, ${counts} patches apply`;
  return `${out}, ${counts} apply: ${c.failing.join(", ")} ${c.failing.length === 1 ? "fails" : "fail"}`;
}

 * `force`; re-patching an untested install keeps it forced.
 */

  const installed = listInstalls(o.paths).find((a) => a.appId === appId);
  const current = installed?.current;
  if (!installed || !current) throw new Error(`${appId} is not installed; install it with revamp patch ${appId}`);
  await refreshSources(o.paths, o).then((lines) => lines.forEach((l) => o.log?.(l)));
  const { bundlePath, source, app, latest } = await newest(appId, o);
  const update = { appId, appName: app.name, current, latest };
  if (compareVersions(latest, current) > 0) return { ...update, result: await patchApp({ ...o, appId: app.id, bundlePath, version: latest }) };
  if (!bundleChanged(installed, source)) return update;
  const force = o.force || receiptOf(installed)?.release.untested;
  return { ...update, result: await patchApp({ ...o, appId: app.id, bundlePath, version: current, force }) };
}

// What Revamp keeps on disk, and what can go: release downloads, cached bundles and installed versions.
import { existsSync, lstatSync, readdirSync, rmSync } from "node:fs";
import { join } from "node:path";
import { loadSources } from "./bundle-sources.ts";
import { listInstalls, lockApp } from "./install.ts";
import { appDir, type Paths } from "./paths.ts";

export interface StorageItem {
  /** "release:<app>/<version>", "bundle:<sha256>" or "install:<app>/<version>". */
  id: string;
  kind: "release" | "bundle" | "install";
  label: string;
  bytes: number;
  /**
   * Why Revamp keeps it; absent when it can be removed. Downloads of installed versions are kept to re-patch them,
   * pinned bundles are what the sources point at, and each app's current install is the one that runs.
   */
  keep?: "installed" | "pinned" | "current";
}

/** Bytes on disk under `path`, without following symlinks. */
function size(path: string): number {
  const s = lstatSync(path);
  return s.isDirectory() ? readdirSync(path).reduce((total, name) => total + size(join(path, name)), 0) : s.size;
}

const dirs = (path: string) => (existsSync(path) ? readdirSync(path, { withFileTypes: true }).filter((d) => d.isDirectory() && !d.name.startsWith(".")).map((d) => d.name) : []);

export function storageUsage(paths: Paths): StorageItem[] {
  const installs = listInstalls(paths);
  const installed = (app: string, version: string) => installs.some((a) => a.appId === app && a.versions.some((v) => v.version === version));
  const items: StorageItem[] = [];
  const releases = join(paths.cache, "releases");
  for (const app of dirs(releases)) {
    for (const version of dirs(join(releases, app))) {
      items.push({ id: `release:${app}/${version}`, kind: "release", label: `${app} ${version}`, bytes: size(join(releases, app, version)), ...(installed(app, version) && { keep: "installed" as const }) });
    }
  }
  const sources = loadSources(paths);
  const bundles = join(paths.cache, "bundles");
  for (const file of existsSync(bundles) ? readdirSync(bundles).filter((f) => /^[0-9a-f]{64}\.mjs$/.test(f)) : []) {
    const sha = file.slice(0, 64);
    const source = sources.find((s) => s.sha256 === sha);
    items.push({ id: `bundle:${sha}`, kind: "bundle", label: source ? `${source.name} ${source.version}` : `bundle ${sha.slice(0, 12)}`, bytes: size(join(bundles, file)), ...(source && { keep: "pinned" as const }) });
  }
  for (const app of installs) {
    for (const { version } of app.versions) {
      items.push({ id: `install:${app.appId}/${version}`, kind: "install", label: `${app.appId} ${version}`, bytes: size(join(appDir(paths, app.appId), version)), ...(version === app.current && { keep: "current" as const }) });
    }
  }
  return items;
}

/** Removes one item `storageUsage` lists without a `keep` reason; anything else is refused. */
export function removeStorageItem(paths: Paths, id: string): void {
  const item = storageUsage(paths).find((i) => i.id === id);
  if (!item) throw new Error(`nothing called "${id}" in Revamp's storage`);
  if (item.keep) throw new Error(`${item.label} is in use (${item.keep}), so it stays`);
  const [kind, rest] = [item.kind, id.slice(item.kind.length + 1)];
  if (kind === "release") rmSync(join(paths.cache, "releases", ...rest.split("/")), { recursive: true, force: true });
  else if (kind === "bundle") rmSync(join(paths.cache, "bundles", `${rest}.mjs`), { force: true });
  else {
    const [app, version] = rest.split("/");
    const unlock = lockApp(paths, app); // never under a running job for the same app
    try {

// revamp serve (spec §9): JSON-RPC 2.0 for the GUI, one message per line on stdin and stdout. Logs go to stderr.
import { randomUUID } from "node:crypto";
import { existsSync, readFileSync } from "node:fs";
import { join } from "node:path";
import { createInterface } from "node:readline";
import {
  addSource,
  checkUpdates,
  describe,
  listInstalls,
  listPatches,
  loadSelection,
  loadSkipped,
  loadSources,
  patchApp,
  prepareSource,
  refreshSources,
  removeSource,
  removeStorageItem,
  rollback,
  skipVersion,
  storageUsage,
  updateApp,
  type BundleDescription,
  type CheckResult,
  type SourceCandidate,
  type UpdateOptions,
} from "@revamp/engine";
import { bundleFor } from "./bundle-for.ts";
import { formatPatchResult } from "./format.ts";

export interface ServeOptions extends UpdateOptions {
  log: (line: string) => void;
}

type Params = Record<string, unknown>;
type Notify = (method: string, params: unknown) => void;

class RpcError extends Error {
  code: number;
  constructor(code: number, message: string) {
    super(message);
    this.code = code;
  }
}

const INVALID_PARAMS = -32602;
const str = (p: Params, key: string): string => {
  if (typeof p[key] !== "string") throw new RpcError(INVALID_PARAMS, `"${key}" must be a string`);
  return p[key] as string;
};
const optional = <T>(p: Params, key: string, ok: (v: unknown) => boolean, type: string): T | undefined => {
  if (p[key] === undefined) return undefined;
  if (!ok(p[key])) throw new RpcError(INVALID_PARAMS, `"${key}" must be ${type}`);
  return p[key] as T;
};
const optStr = (p: Params, key: string) => optional<string>(p, key, (v) => typeof v === "string", "a string");
const optBool = (p: Params, key: string) => optional<boolean>(p, key, (v) => typeof v === "boolean", "true or false");
const optStrs = (p: Params, key: string) => optional<string[]>(p, key, (v) => Array.isArray(v) && v.every((x) => typeof x === "string"), "a list of strings");

/** Answers one JSON-RPC message; returns the response, or undefined for a notification. Jobs report progress through `notify`. */
export function createHandler(o: ServeOptions): (line: string, notify: Notify) => Promise<object | undefined> {
  const bundle = (appId: string) => bundleFor(o.paths, appId, undefined, o.log, o);
  const descriptions = new Map<string, Promise<BundleDescription>>(); // bundles are content-addressed, so a path's description never changes
  const describeOnce = (path: string) => descriptions.get(path) ?? descriptions.set(path, describe(path)).get(path)!;
  const candidates = new Map<string, SourceCandidate>();
  const lastCheck = (): CheckResult | null => {
    const file = join(o.paths.state, "last-check.json");
    return existsSync(file) ? (JSON.parse(readFileSync(file, "utf8")) as CheckResult) : null;
  };

  /** Installed apps plus the apps the sources offer, so a first install starts from the list too. */
  async function apps() {
    const installs = listInstalls(o.paths);
    const ids = [...new Set([...installs.map((a) => a.appId), ...loadSources(o.paths).flatMap((s) => s.apps)])];
    const list = [];
    for (const id of ids) {
      const installed = installs.find((a) => a.appId === id);
      let name = id;
      try {
        name = (await describeOnce(await bundle(id))).apps.find((a) => a.id === id)?.name ?? id;
      } catch (e) {
        o.log(`${id}: ${e instanceof Error ? e.message : String(e)}`);
      }
      const versions = (installed?.versions ?? []).map(({ version, receipt }) => ({
        version,
        installedAt: receipt.installedAt,
        bundle: { name: receipt.bundle.name, version: receipt.bundle.version },
        untested: receipt.release.untested ?? false,
      }));
      list.push({ appId: id, name, current: installed?.current ?? null, versions });
    }
    return { apps: list, lastCheck: lastCheck(), skipped: loadSkipped(o.paths) };
  }

  const methods: Record<string, (p: Params, id: unknown, notify: Notify) => unknown> = {
    "apps.list": () => apps(),
    "patches.list": async (p) => {
      const appId = str(p, "appId");
      return { ...(await listPatches(await bundle(appId), appId, optStr(p, "version"))), selection: loadSelection(o.paths, appId) };
    },
    "selection.get": (p) => loadSelection(o.paths, str(p, "appId")),
    "job.patch": async (p, id, notify) => {
      const appId = str(p, "appId");
      const result = await patchApp({
        ...o,
        appId,
        bundlePath: await bundle(appId),
        version: optStr(p, "version"),
        force: optBool(p, "force"),
        dryRun: optBool(p, "dryRun"),
        enable: optStrs(p, "enable"),
        disable: optStrs(p, "disable"),
        options: optStrs(p, "options"),
        progress: (e) => notify("job.progress", { id, ...e }),
      });
      return { result, report: formatPatchResult(result) };
    },
    "job.update": async (p, id, notify) => {
      const update = await updateApp(str(p, "appId"), { ...o, force: optBool(p, "force"), progress: (e) => notify("job.progress", { id, ...e }) });
      return { ...update, ...(update.result && { report: formatPatchResult(update.result) }) };
    },
    "install.rollback": (p) => ({ current: rollback(o.paths, str(p, "appId")) }),
    "check.run": () => checkUpdates(o),
    "check.last": () => lastCheck(),
    "check.skip": (p) => {
      skipVersion(o.paths, str(p, "appId"), p.version === null ? null : str(p, "version"));
      return {};
    },
    "sources.list": () => loadSources(o.paths),
    "sources.prepare": async (p) => {
      const candidate = await prepareSource(o.paths, str(p, "location"), o);
      const token = randomUUID();
      candidates.set(token, candidate);
      const { manifest, apps } = candidate.description;
      return { token, source: candidate.source, manifest, apps: apps.map((a) => ({ id: a.id, name: a.name, versions: Object.keys(a.versions) })), changelog: candidate.changelog };
    },
    // Only a candidate this session prepared can be trusted: the pin is what the user saw, not what a message claims.
    "sources.add": (p) => {
      const token = str(p, "token");
      const candidate = candidates.get(token);
      if (!candidate) throw new RpcError(INVALID_PARAMS, "that source preview is gone; fetch the source again");
      candidates.delete(token);
      addSource(o.paths, candidate.source);
      return candidate.source;
    },
    "sources.remove": (p) => removeSource(o.paths, str(p, "location")),
    "sources.refresh": () => refreshSources(o.paths, o),
    "storage.list": () => storageUsage(o.paths),
    "storage.remove": (p) => {
      removeStorageItem(o.paths, str(p, "id"));
      return {};
    },
  };

  return async (line, notify) => {
    let message: { jsonrpc?: unknown; id?: unknown; method?: unknown; params?: unknown };
    try {
      message = JSON.parse(line);
    } catch {
      return { jsonrpc: "2.0", id: null, error: { code: -32700, message: "Parse error" } };
    }
    const id = message?.id;
    const reply = (body: object) => (id === undefined ? undefined : { jsonrpc: "2.0", id, ...body });
    if (message?.jsonrpc !== "2.0" || typeof message.method !== "string") return { jsonrpc: "2.0", id: id ?? null, error: { code: -32600, message: "Invalid Request" } };
    const method = Object.hasOwn(methods, message.method) ? methods[message.method] : undefined;
    if (!method) return reply({ error: { code: -32601, message: `Method not found: ${message.method}` } });
    const params = message.params ?? {};
    if (typeof params !== "object" || params === null || Array.isArray(params)) return reply({ error: { code: INVALID_PARAMS, message: "params must be an object" } });
    try {
      return reply({ result: (await method(params as Params, id, notify)) ?? null });
    } catch (e) {
      return reply({ error: { code: e instanceof RpcError ? e.code : -32000, message: e instanceof Error ? e.message : String(e) } });
    }
  };
}

/** Serves until stdin closes, then waits for running requests to finish. */
export function serve(o: ServeOptions, input: NodeJS.ReadableStream = process.stdin, output: NodeJS.WritableStream = process.stdout): Promise<void> {
  const handle = createHandler(o);
  const send = (message: object) => void output.write(`${JSON.stringify(message)}\n`);
  const running = new Set<Promise<void>>();
  const lines = createInterface({ input });
  lines.on("line", (line) => {
    if (!line.trim()) return;
    const job = handle(line, (method, params) => send({ jsonrpc: "2.0", method, params })).then((response) => response && send(response));
    running.add(job);
    void job.finally(() => running.delete(job));
  });
  return new Promise((resolve) => lines.on("close", () => void Promise.allSettled([...running]).then(() => resolve())));
}

```ts
// JSON-RPC 2.0 client for `revamp serve`: requests by id, notifications (job.progress) to listeners.

export interface Transport {
  send(line: string): void;
  onLine(listener: (line: string) => void): void;
}

export class RpcError extends Error {
  code: number;
  constructor(code: number, message: string) {
    super(message);
    this.code = code;
  }
}

export interface Rpc {
  call<T>(method: string, params?: object): Promise<T>;
  /** Returns the unsubscribe function. */
  onNotification(listener: (method: string, params: unknown) => void): () => void;
}

export function rpcClient(transport: Transport): Rpc {
  let next = 1;
  const pending = new Map<number, { resolve: (v: unknown) => void; reject: (e: Error) => void }>();
  const listeners = new Set<(method: string, params: unknown) => void>();
  transport.onLine((line) => {
    let message: { id?: number; result?: unknown; error?: { code: number; message: string }; method?: string; params?: unknown };
    try {
      message = JSON.parse(line);
    } catch {
      return console.warn("revamp serve sent a line that isn't JSON:", line);
    }
    if (typeof message.method === "string") return listeners.forEach((l) => l(message.method!, message.params));
    const waiting = message.id === undefined ? undefined : pending.get(message.id);
    if (!waiting) return;
    pending.delete(message.id!);
    if (message.error) waiting.reject(new RpcError(message.error.code, message.error.message));
    else waiting.resolve(message.result);
  });
  return {
    call: <T>(method: string, params?: object) =>
      new Promise<T>((resolve, reject) => {
        const id = next++;
        pending.set(id, { resolve: resolve as (v: unknown) => void, reject });
        transport.send(JSON.stringify({ jsonrpc: "2.0", id, method, ...(params && { params }) }));
      }),
    onNotification(listener) {
      listeners.add(listener);
      return () => void listeners.delete(listener);
    },
  };
}

// What the screens show, as plain functions the Node tests can run (no React, no Tauri).
import type { AppCheck, CheckResult, JobProgress, StorageItem } from "@revamp/engine";

export interface AppRow {
  appId: string;
  name: string;
  current: string | null;
  versions: Array<{ version: string; installedAt: string; bundle: { name: string; version: string }; untested: boolean }>;
}

export interface AppsList {
  apps: AppRow[];
  lastCheck: CheckResult | null;
  skipped: Record<string, string>;
}

export type Badge = { kind: "release" | "patches" | "ok" | "skipped" | "failed" | "new"; label: string };

/** The sidebar badge: a new release, new patches for the installed version, or nothing to do. */
export function badgeFor(app: AppRow, check: AppCheck | undefined): Badge {
  if (!app.current) return { kind: "new", label: "Not installed" };
  if (!check || check.current !== app.current) return { kind: "ok", label: app.current };
  if (check.status === "update") return { kind: "release", label: `${check.latest} out` };
  if (check.status === "patches") return { kind: "patches", label: "New patches" };
  if (check.status === "skipped") return { kind: "skipped", label: `Skipped ${check.latest}` };
  if (check.status === "failed") return { kind: "failed", label: "Check failed" };
  return { kind: "ok", label: "Up to date" };
}

export const checkFor = (list: AppsList, appId: string) => list.lastCheck?.apps.find((a) => a.appId === appId);

/** Apps that "Update all" would touch: a newer release or new patches, never a skipped release. */
export const pendingUpdates = (list: AppsList): string[] =>
  list.apps.filter((a) => a.current && ["release", "patches"].includes(badgeFor(a, checkFor(list, a.appId)).kind)).map((a) => a.appId);

export interface PatchRow {
  name: string;
  description: string;
  default: boolean;
  required: boolean;
  compatible: boolean;
  options: Record<string, { type: string; title: string; description: string; default: unknown }>;
}

export interface Selection {
  enable: string[];
  disable: string[];
  options: Record<string, Record<string, unknown>>;
}

/** Whether each patch starts switched on: required ones always, then the saved choice, then the patch's default. */
export function initialToggles(patches: PatchRow[], saved: Selection): Record<string, boolean> {
  const on = (p: PatchRow) => p.required || saved.enable.includes(p.name) || (p.default && !saved.disable.includes(p.name));
  return Object.fromEntries(patches.filter((p) => p.compatible).map((p) => [p.name, on(p)]));
}

/** The toggles as the job's enable/disable lists; required patches are left to the engine. */
export function selectionFlags(patches: PatchRow[], toggles: Record<string, boolean>): { enable: string[]; disable: string[] } {
  const choosable = patches.filter((p) => p.compatible && !p.required);
  return { enable: choosable.filter((p) => toggles[p.name]).map((p) => p.name), disable: choosable.filter((p) => !toggles[p.name]).map((p) => p.name) };
}

/** Option values as `--option` strings, only for values that differ from the patch's default. */
export function optionFlags(patches: PatchRow[], values: Record<string, Record<string, unknown>>): string[] {
  return patches.flatMap((p) =>
    Object.entries(values[p.name] ?? {})
      .filter(([key, value]) => Object.hasOwn(p.options, key) && value !== p.options[key].default)
      .map(([key, value]) => `${p.name}:${key}=${String(value)}`),
  );
}

const STEP: Record<JobProgress["step"], string> = { download: "Downloading", extract: "Extracting", patch: "Patching", repack: "Repacking", install: "Installing" };

export function progressLabel(e: JobProgress): string {
  if (e.step === "download" && e.percent !== undefined) return `Downloading ${e.percent}%`;
  if (e.step === "patch" && e.patch) return `Patching: ${e.patch} (${e.index}/${e.total})`;
  return `${STEP[e.step]}…`;
}

export function formatBytes(bytes: number): string {
  if (bytes < 1024) return `${bytes} B`;
  if (bytes < 1024 ** 2) return `${Math.round(bytes / 1024)} KB`;
  if (bytes < 1024 ** 3) return `${Math.round(bytes / 1024 ** 2)} MB`;
  return `${(bytes / 1024 ** 3).toFixed(1)} GB`;
}

export const reclaimable = (items: StorageItem[]) => items.filter((i) => !i.keep).reduce((total, i) => total + i.bytes, 0);

type View = { kind: "app"; appId: string } | { kind: "sources" } | { kind: "storage" };

export function App({ rpc }: { rpc: Rpc }) {
  const [list, setList] = useState<AppsList | null>(null);
  const [view, setView] = useState<View | null>(null);
  const [busy, setBusy] = useState<string | null>(null);
  const [error, setError] = useState<string | null>(null);

  const refresh = useCallback(async () => {
    const next = await rpc.call<AppsList>("apps.list");
    setList(next);
    setView((v) => v ?? (next.apps[0] ? { kind: "app", appId: next.apps[0].appId } : { kind: "sources" }));
  }, [rpc]);
  useEffect(() => void refresh().catch((e: Error) => setError(e.message)), [refresh]);

  const task = async (label: string, work: () => Promise<void>) => {
    setBusy(label);
    setError(null);
    try {
      await work();
    } catch (e) {
      setError((e as Error).message);
    } finally {
      setBusy(null);
      await refresh().catch(() => {});
    }
  };
  const checkNow = () => task("Checking…", () => rpc.call("check.run"));
  const updateAll = () =>
    task("Updating…", async () => {
      const failed: string[] = [];
      for (const appId of pendingUpdates(list!)) {
        setBusy(`Updating ${list!.apps.find((a) => a.appId === appId)!.name}…`);
        await rpc.call("job.update", { appId }).catch((e: Error) => failed.push(`${appId}: ${e.message}`));

import type { AppCheck, JobProgress, PatchAppResult, PatchResult } from "@revamp/engine";
import { useEffect, useState } from "react";
import { initialToggles, optionFlags, progressLabel, selectionFlags, type AppRow, type PatchRow, type Selection } from "./model.ts";
import { notifyDone } from "./platform.ts";
import type { Rpc } from "./rpc.ts";

interface Listing {
  app: { name: string; versions: Record<string, { experimental?: boolean }> };
  version: string;
  listed: boolean;
  bundle: { name: string; version: string };
  patches: PatchRow[];
  selection: Selection;
}

interface Outcome {
  result: PatchAppResult;
  report: string;
}

const failedOrSkipped = (r: PatchResult) => !r.internal && (r.status === "failed" || r.status === "skipped");

export function AppDetail({ rpc, app, check, onChanged }: { rpc: Rpc; app: AppRow; check: AppCheck | undefined; onChanged: () => Promise<void> }) {
  const [version, setVersion] = useState<string | undefined>(app.current ?? undefined);
  const [listing, setListing] = useState<Listing | null>(null);
  const [toggles, setToggles] = useState<Record<string, boolean>>({});
  const [values, setValues] = useState<Record<string, Record<string, unknown>>>({});
  const [progress, setProgress] = useState<string | null>(null);
  const [outcome, setOutcome] = useState<Outcome | null>(null);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    setListing(null);
    rpc.call<Listing>("patches.list", { appId: app.appId, ...(version && { version }) }).then((l) => {
      setListing(l);
      setVersion(l.version);
      setToggles(initialToggles(l.patches, l.selection));
      setValues(l.selection.options);
    }, (e: Error) => setError(e.message));
  }, [rpc, app.appId, version]);

  const latest = check?.status === "update" || check?.status === "skipped" ? check.latest : undefined;
  const versions = listing ? [...new Set([...Object.keys(listing.app.versions), ...(latest ? [latest] : []), ...(app.current ? [app.current] : [])])] : [];
  const experimental = !!listing?.app.versions[listing.version]?.experimental;
  const untested = listing ? !listing.listed : false;

  async function run(dryRun: boolean) {
    if (!listing) return;
    setOutcome(null);
    setError(null);
    setProgress("Starting…");
    const stop = rpc.onNotification((method, params) => method === "job.progress" && setProgress(progressLabel(params as JobProgress)));
    try {
      const out = await rpc.call<Outcome>("job.patch", {
        appId: app.appId,
        version: listing.version,
        ...selectionFlags(listing.patches, toggles),
        options: optionFlags(listing.patches, values),
        force: untested || experimental,
        dryRun,
      });
      setOutcome(out);
      const head = out.report.split("\n")[0];
      await notifyDone(head);
      if (!dryRun) await onChanged();
    } catch (e) {
      setError((e as Error).message);
    } finally {
      stop();
      setProgress(null);
    }
  }

  const skip = (v: string | null) => rpc.call("check.skip", { appId: app.appId, version: v }).then(onChanged, (e: Error) => setError(e.message));
  const rollback = () => rpc.call("install.rollback", { appId: app.appId }).then(onChanged, (e: Error) => setError(e.message));

  if (outcome && (outcome.result.aborted || outcome.result.results.some(failedOrSkipped))) {
    return (
      <section>
        <h2>
          {app.name} {outcome.result.version}: {outcome.result.aborted ? "the job stopped" : "some patches didn't apply"}
        </h2>
        <p className="muted">{outcome.result.installed ? `Installed anyway, without the patches marked ✗ or –.` : `Nothing changed in your installed ${app.name}.`}</p>
        <pre className="report">{outcome.report}</pre>
        <div className="row-actions">
          <button className="primary" onClick={() => setOutcome(null)}>
            Back to patch selection
          </button>
          <button onClick={() => void navigator.clipboard.writeText(outcome.report)}>Copy report</button>
        </div>
        <p className="muted">Send the copied report to the bundle's author: it names the patch, the step that failed and the file.</p>
      </section>
    );
  }

  const current = app.versions.find((v) => v.version === app.current);
  const isUpdate = !!app.current && listing?.version !== app.current;
  const label = !app.current ? `Patch and install ${listing?.version ?? ""}` : isUpdate ? `Update to ${listing?.version}` : check?.status === "patches" ? `Re-patch ${app.current}` : `Patch ${listing?.version ?? ""}`;
  return (
    <section>
      <h2>{app.name} (Revamped)</h2>
      <p className="muted">
        {current ? `${current.version} · installed ${new Date(current.installedAt).toLocaleString()} · patched with ${current.bundle.name} ${current.bundle.version}` : "Not installed yet"}
      </p>
      {check?.status === "update" && (
        <div className="banner warning">
          New release: {app.name} {check.latest} is out.{" "}
          {check.listed ? `A dry run says ${check.applied}/${check.total} patches apply.` : `It isn't in your bundle yet; a dry run says ${check.applied}/${check.total} patches apply.`}
          <div className="row-actions">
            <button onClick={() => setVersion(check.latest)}>Review {check.latest}</button>
            <button onClick={() => skip(check.latest!)}>Skip {check.latest}</button>
          </div>
        </div>
      )}
      {check?.status === "skipped" && (
        <div className="banner">
          Skipped {check.latest}. You'll hear about the next release. <button className="link" onClick={() => skip(null)}>Undo</button>
        </div>
      )}
      {check?.status === "patches" && (
        <div className="banner accent">
          New patches: {check.bundle!.name} {check.bundle!.version} {check.newPatches?.length ? `adds ${check.newPatches.join(", ")} for` : "is out for"} your {app.name} {app.current}. Re-patch to use it.
          {check.bundle!.changelog && <pre className="report">{check.bundle!.changelog}</pre>}
        </div>
      )}
      {error && <pre className="banner danger">{error}</pre>}
      {listing && (
        <>
          <label className="field">
            <span className="muted">Version</span>
            <select value={listing.version} disabled={progress !== null} onChange={(e) => setVersion(e.target.value)}>
              {versions.map((v) => (
                <option key={v} value={v}>
                  {v} — {listing.app.versions[v] ? (listing.app.versions[v].experimental ? "experimental in your bundle" : "in your bundle") : "not in your bundle yet"}
                </option>
              ))}
            </select>
          </label>
          {(untested || experimental) && <p className="muted warn">{untested ? "Untested: checked only against GitHub's SHA-256." : "Experimental in your bundle."}</p>}
          <ul className="patches">
            {listing.patches
              .filter((p) => p.compatible)
              .map((p) => {
                const r = outcome?.result.results.find((x) => x.name === p.name);
                return (
                  <li key={p.name}>
                    <input type="checkbox" checked={!!toggles[p.name]} disabled={p.required || progress !== null} onChange={(e) => setToggles({ ...toggles, [p.name]: e.target.checked })} aria-label={p.name} />
                    <div>
                      <div>
                        {p.name} {p.required && <span className="pill">required</span>}
                        {check?.newPatches?.includes(p.name) && <span className="pill patches">new</span>}
                      </div>
                      <div className="muted">{p.description}</div>
                      {Object.entries(p.options).map(([key, o]) => {
                        const value = values[p.name]?.[key] ?? o.default;
                        const set = (v: unknown) => setValues({ ...values, [p.name]: { ...values[p.name], [key]: v } });
                        return (
                          <label key={key} className="option muted">
                            {o.type === "bool" ? <input type="checkbox" checked={value === true} onChange={(e) => set(e.target.checked)} /> : null}
                            {o.title}
                            {o.type !== "bool" && <input value={String(value ?? "")} onChange={(e) => set(o.type === "number" ? Number(e.target.value) : e.target.value)} />}
                          </label>
                        );
                      })}
                      {r && <div className={`status ${r.status}`}>{r.status === "applied" ? "✓ applied" : r.status}</div>}
                    </div>
                  </li>
                );
              })}
          </ul>
          <div className="row-actions">
            <button className="primary" disabled={progress !== null} onClick={() => run(false)}>
              {label}
            </button>
            <button disabled={progress !== null} onClick={() => run(true)}>
              Dry run
            </button>
            <span className="muted">{progress ?? (outcome ? outcome.report.split("\n")[0] : "")}</span>
          </div>
        </>
      )}
      {app.versions.length > 0 && (
        <>
          <h3>Installed versions</h3>
          <ul className="versions">
            {app.versions.map((v) => (
              <li key={v.version}>
                <span>
                  {v.version} <span className="muted">· {new Date(v.installedAt).toLocaleString()} · {v.bundle.name} {v.bundle.version}{v.untested ? " · untested" : ""}</span>
                </span>
                {v.version === app.current ? <span className="pill accent">current</span> : <button onClick={rollback}>Roll back</button>}
              </li>
            ))}
          </ul>
        </>
      )}
    </section>
  );
}

import type { StorageItem } from "@revamp/engine";
import { useEffect, useState } from "react";
import { formatBytes, reclaimable } from "./model.ts";
import type { Rpc } from "./rpc.ts";

const GROUPS: Array<[StorageItem["kind"], string]> = [
  ["release", "Downloaded releases"],
  ["bundle", "Bundles"],
  ["install", "Installed apps"],
];
const KEEP: Record<NonNullable<StorageItem["keep"]>, string> = { installed: "installed", pinned: "pinned", current: "current" };

export function Storage({ rpc }: { rpc: Rpc }) {
  const [items, setItems] = useState<StorageItem[] | null>(null);
  const [error, setError] = useState<string | null>(null);
  const load = () => rpc.call<StorageItem[]>("storage.list").then(setItems, (e: Error) => setError(e.message));
  useEffect(() => void load(), [rpc]);
  const remove = async (ids: string[]) => {
    setError(null);
    for (const id of ids) await rpc.call("storage.remove", { id }).catch((e: Error) => setError(e.message));
    await load();
  };
  if (!items) return <p className="muted">{error ?? "Measuring…"}</p>;
  const free = reclaimable(items);
  return (
    <section>
      <h2>Storage</h2>
      <p className="muted">
        {formatBytes(items.reduce((t, i) => t + i.bytes, 0))} used by Revamp · {free ? `${formatBytes(free)} can be freed` : "nothing to free"}
      </p>
      {free > 0 && (
        <button className="primary" onClick={() => remove(items.filter((i) => !i.keep).map((i) => i.id))}>
          Free {formatBytes(free)}
        </button>
      )}
      {error && <pre className="banner danger">{error}</pre>}
      {GROUPS.map(([kind, title]) => (
        <div className="card" key={kind}>
          <h3>{title}</h3>
          <ul className="versions">
            {items
              .filter((i) => i.kind === kind)
              .map((i) => (
                <li key={i.id}>
                  <span>{i.label}</span>
                  <span className="muted">{formatBytes(i.bytes)}</span>
                  {i.keep ? <span className="pill">{KEEP[i.keep]}</span> : <button onClick={() => remove([i.id])}>Remove</button>}
                </li>
              ))}
          </ul>
        </div>
      ))}
      <p className="muted">
        Kept automatically: downloads of installed versions, the pinned bundle of each source, and each app's current install. A removed download is fetched again when needed; removing an older install takes away its roll back.
      </p>
    </section>
  );
}

// node packages/gui/scripts/icon.ts: draws the Revamp icon (two offset layers on a blue tile) into src-tauri/icons/icon.png.
// Shapes are signed-distance rounded rectangles, so edges are anti-aliased without an image library.
import { writeFileSync } from "node:fs";
import { fileURLToPath } from "node:url";
import { crc32, deflateSync } from "node:zlib";

const SIZE = 512;
type Rgba = [number, number, number, number];

/** Signed distance from (x, y) to a rounded rectangle centred at (cx, cy) with half-size (hw, hh) and corner radius r. */
function roundRect(x: number, y: number, cx: number, cy: number, hw: number, hh: number, r: number): number {
  const qx = Math.abs(x - cx) - hw + r;
  const qy = Math.abs(y - cy) - hh + r;
  return Math.hypot(Math.max(qx, 0), Math.max(qy, 0)) + Math.min(Math.max(qx, qy), 0) - r;
}

const coverage = (d: number) => Math.min(1, Math.max(0, 0.5 - d));
const layers: Array<{ shape: (x: number, y: number) => number; color: Rgba }> = [
  { shape: (x, y) => roundRect(x, y, 256, 256, 240, 240, 112), color: [24, 95, 165, 255] },
  { shape: (x, y) => roundRect(x, y, 226, 226, 120, 120, 44), color: [133, 183, 235, 255] },
  { shape: (x, y) => roundRect(x, y, 290, 290, 120, 120, 44), color: [255, 255, 255, 235] },
];

const pixels = Buffer.alloc(SIZE * (SIZE * 4 + 1)); // one filter byte (0) per row
for (let y = 0; y < SIZE; y++) {
  for (let x = 0; x < SIZE; x++) {
    let [r, g, b, a] = [0, 0, 0, 0];
    for (const { shape, color } of layers) {
      const alpha = (coverage(shape(x + 0.5, y + 0.5)) * color[3]) / 255;
      const out = alpha + (a / 255) * (1 - alpha);
      if (out === 0) continue;
      [r, g, b] = [0, 1, 2].map((i) => (color[i] * alpha + [r, g, b][i] * (a / 255) * (1 - alpha)) / out);
      a = out * 255;
    }
    pixels.set([r, g, b, a].map(Math.round), y * (SIZE * 4 + 1) + 1 + x * 4);
  }
}

const chunk = (type: string, data: Buffer) => {
  const body = Buffer.concat([Buffer.from(type, "ascii"), data]);
  const out = Buffer.alloc(body.length + 8);
  out.writeUInt32BE(data.length, 0);
  body.copy(out, 4);
  out.writeUInt32BE(crc32(body), body.length + 4);
  return out;
};
const header = Buffer.alloc(13);
header.writeUInt32BE(SIZE, 0);
header.writeUInt32BE(SIZE, 4);
header.set([8, 6, 0, 0, 0], 8); // 8-bit RGBA, no interlace
const png = Buffer.concat([Buffer.from([137, 80, 78, 71, 13, 10, 26, 10]), chunk("IHDR", header), chunk("IDAT", deflateSync(pixels)), chunk("IEND", Buffer.alloc(0))]);
writeFileSync(fileURLToPath(new URL("../src-tauri/icons/icon.png", import.meta.url)), png);
console.log(`src-tauri/icons/icon.png written (${SIZE}×${SIZE}, ${png.length} bytes)`);
```

// revamp check --notify (spec §7.3, §9): one desktop notification for everything the check found. With the GUI
// installed it carries an "Open Revamp" action, which starts the window in its own systemd user unit so it outlives
// the check (a timer's service is stopped, with its processes, when it ends).
import { spawnSync } from "node:child_process";

type Run = (command: string, args: string[], options: { encoding?: "utf8"; timeout?: number; stdio?: "ignore" }) => { stdout?: string | Buffer | null };

export function notifyCheck(lines: string[], gui: string | undefined, run: Run = spawnSync): void {
  if (lines.length === 0) return;
  const body = lines.join("\n");
  // notify-send is optional: without it the lines are still in the timer's journal.
  if (!gui) return void run("notify-send", ["--app-name=Revamp", "Revamp", body], { stdio: "ignore" });
  // -A waits for the click; after ten minutes the check stops waiting and ends.
  const r = run("notify-send", ["--app-name=Revamp", "--action=open=Open Revamp", "Revamp", body], { encoding: "utf8", timeout: 600_000 });
  if (String(r.stdout ?? "").trim() === "open") run("systemd-run", ["--user", "--collect", "--quiet", gui], { stdio: "ignore" });
}

5. **Storage.** It lists the downloads, the bundle and both installs with their sizes. The Hydra 4.0.6 download (147 MB, not installed) has a Remove button; installed versions and the pinned bundle are marked kept. Freeing it is your choice.
6. **Background notification.** Start a Hydra dry run and switch to another window. When it ends, a "Revamp" notification shows the result line.
7. **"Open Revamp".** The daily check offers it the next time an app has news. To see it now, close Revamp and run `systemctl --user start revamp-check.service`: with nothing new there is no notification, as before.
